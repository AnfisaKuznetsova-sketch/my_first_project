# Эмулятор терминала

## 1. Общее описание
Проект представляет собой простой графический эмулятор командной строки, написанный на языке Python с использованием библиотеки Tkinter. Программа позволяет вводить базовые команды и отображает результат их выполнения в текстовом поле.

## 2. Описание всех функций и настроек
*   **Главное окно:** Создаётся с помощью `tk.Tk()`, имеет заголовок с именем пользователя и хоста, а также размеры 700x600 пикселей.
*   **Область вывода (`scrolledtext.ScrolledText`):** Текстовое поле с черным фоном и белым текстом, предназначенное только для чтения (state="disabled"). Используется для отображения введённых команд и результатов их работы.
*   **Строка ввода (`tk.Entry`):** Поле для ввода команд, расположенное в нижней части окна. Имеет шрифт Consolas, черный фон и белый текст для удобства чтения.
*   **Функция `show(text)`:** Выводит переданный текст в область вывода, временно включая её для редактирования и отключая обратно.
*   **Обработка команд:** Считывает введённую строку, обрабатывает команды `ls`, `cd`, `exit`. Для команды `exit` закрывает приложение, для `ls` выводит список файлов (эмуляция), для `cd` меняет текущую директорию (эмуляция).

## 3. Описание команд для сборки проекта и запуска тестов
Для запуска проекта не требуется сборка. Достаточно иметь установленный Python 3.
*   **Запуск проекта:** `python src/proga.py` (или запустить файл `run.bat` в Windows).
*   **Запуск тестов:** Тесты находятся в папке `tests`. Для их запуска используйте команду `python -m pytest tests/` (при наличии установленного пакета pytest).

## 4. Примеры использования
После запуска программы в строке ввода можно ввести следующие команды:

*   Ввод команды `ls` выведет список файлов в текущей директории.
*   Ввод команды `cd ..` (эмуляция) переместит вас на уровень выше.
*   Ввод команды `exit` закроет приложение.
